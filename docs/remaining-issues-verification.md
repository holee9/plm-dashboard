기준: 운영 d4266fc. 범위: #59/#61/#62/#63/#65/#66/#68. #64는 사용자 지시로 제외.

## 변경 및 사이드이펙트 검토

- 근거 없는 완료율 증감 및 동작하지 않는 기간 버튼 제거. 데이터 필터 계약은 변경하지 않음.
- Board/Timeline/Risks 표시 제한 제거, 기존 필터와 WP 링크 유지. Board 컬럼과 Timeline은 스크롤로 전체 접근.
- 내비게이션 button·이름·현재 화면·focus-visible 제공, 렌더링 후 선택 버튼으로 포커스 복원.
- 부하율 입력 부족을 null로 모델링. 해당 화면의 차트·표·집계에서 산출 불가와 실제 0 구분. 일정 압박 유지.
- 중복 번역 제거, 빈 번다운·마일스톤 압축, 라이트 보조 텍스트 색상 개선. 8:5 레이아웃 유지.
- 앞선 운영 배포 검증 기록 보정.

## 검증

- Node 회귀 테스트: 17개 통과. 누락/정상/실제 0 부하, 시간 기록 없는 유효 부하, 90건 전체 접근, 필터 유지, 의미 있는 내비게이션, 기존 핸드오프 계약 회귀 포함.
- JS 전체 구문 검사, git diff --check 통과.
- 격리 8081 서버와 운영 API: 576 WP/37프로젝트/15명 로딩.
- Board 카드 576개 전부 표시, BLUE HD Timeline 작업 링크 29개(+마일스톤 행).
- Resources 산출 불가 안내, Risks 과부하 총수 입력 필요 표시. 실제 55개 지연 유지.
- Tab/Enter/Space로 화면 전환·사이드바 조작, 선택 화면으로 포커스 복원 확인.
- 라이트/다크 실제 화면 확인, 빈 번다운 패널 124px로 압축.

## 배포

원본 main에 병합된 뒤 raspi5p에서 git pull --ff-only로 반영한다. 정적 파일 변경이므로 Docker 재시작 불필요.
Chrome은 배포 후 강력 새로고침(Ctrl+Shift+R, Mac Cmd+Shift+R)이 필요할 수 있다.
이번 개선의 운영 서버 적용은 아직 수행하지 않았다. 운영 적용 후 위 항목을 재확인한다.
